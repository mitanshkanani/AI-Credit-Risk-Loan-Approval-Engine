On free hosting the first visit after a quiet period can take up to a minute.
How it works: raw application → fitted preprocessing (imputation, one-hot, target encoding) → LightGBM with monotonic constraints (146 features) → Platt calibration → decision policy (approve if PD ≤ 22.5%, decline if PD ≥ 27.5%) → expected loss = PD × amount × exposure × loss-given-default → SHAP reason codes. The model never sees LendingClub's grade or interest rate.
Limitations:
Educational project. Not a real credit decision.
